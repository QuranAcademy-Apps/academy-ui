# Исправления дизайн системы Academy UI

Дата: 4 октября 2026 года. Изменения выполнены по [ревизии дизайн системы](2026-10-04-design-system-audit.md) отдельными агентами по компонентам, инфраструктуре и каталогу. Общие проверки и интеграция выполнены в основной рабочей копии. Предыдущие пользовательские изменения сохранены.

## Выполненные изменения

| Замечание | Результат |
| --- | --- |
| DS01 | `table`, `surface`, `disclosure` независимы. Значения по умолчанию 24/14/14. Каждый контейнер использует собственную роль. Nullable-параметры конструктора сохранены. |
| DS02 | Chevron передает логическое направление; зеркалирование выполняется один раз общим SF renderer. |
| DS03 | Основные подписи обычной строки и строки значения используют `bodyRow`; переопределение роли и высота строки применяются одинаково. |
| DS04 | Вкладки «Компоненты», «Примеры», «Настройки». Все семейства компонентов перечислены на главном экране под заголовками групп; открываются одним нажатием. Примеры готовых экранов также открываются сразу. Группы и поиск строятся по реестру. |
| DS05 | TableBody получает отступ через `AcademyTableRowGeometry`; для собственного виджета есть `AcademyTableRowLayout`. Конкретные классы меню больше не нужны таблице для расчета разделителя. |
| DS06 | Button и ActionButton используют общий внутренний расчет состояния и цветов. Pending блокирует активацию и объявляет локализованное состояние загрузки. |
| DS07 | Pill имеет собственные роли радиуса и padding. Размеры иконок Pill/Action не зависят от table/timeline. |
| DS08 | ExpandingSearch использует AcademyTextInput в chrome-режиме. Сохранены анимация, фокус и очистка при закрытии; доступны внешний FocusNode, enabled/readOnly и onSubmitted. |
| DS09 | Общий механизм маски поверхностей находится в foundation/surface. Старый путь modal сохранен переэкспортом. |
| DS10 | RowScope отделен от визуального Divider; InfoButton находится в семействе кнопок. Старые импорты сохранены; уровни API описаны в документации. |
| DS11 | Руководство выбора, роли типографики и структура системы актуализированы. Независимые текстовые overrides не объединены механически по совпадению размера. |
| DS12 | Старые токены и пути описаны как совместимость; канонические роли указаны. Их удаление не выполнялось без проверки внешних клиентов. |
| DS13 | Канонические страницы компонентов, поиск по API, связанные компоненты и ссылки на сценарии используют единый реестр. На страницах доступны проверки оформления и применимые состояния. |
| DS14 | Область применения grouped-таблицы явно ограничена короткими списками и настройками. Документация объясняет, что ленивость по секциям не делает строки большой секции ленивыми. Новый builder/sliver API не введен без реального сценария и измерения. |

Для DS12 и DS14 исправлен контракт использования и документация. Это не удаление потенциально используемого API и не заявление о доказанном ускорении: внешний код потребителей и производительность больших списков не исследовались в этой задаче.

## Совместимость клиентских настроек

Публичный импорт `package:academy_ui/academy_ui.dart` остается прежним. Старые пути маски поверхности, аксессуаров и Divider переэкспортируют соответствующие реализации. Не удалены старые текстовые роли, CompactSegment и прежние константы AcademyTokens.

Меняется намеренная связь настроек: раньше `surface` и `disclosure` являлись алиасами `table`. Теперь это самостоятельные роли. Если приложение хотело одинаковое скругление всех трех контейнеров, оно должно явно передать все три параметра. Аналогично, оформление Pill следует переопределять через `pillButton`, а не через настройки меню. Эти изменения восстанавливают правила APPLE_HIG.md и отделяют независимые компоненты.

Настройки радиусов по-прежнему допускают nullable-значения конструктора, поэтому существующий код с необязательными клиентскими параметрами продолжает компилироваться.

## Проверки

Полная библиотека: **214 тестов прошли**, анализатор не нашел замечаний. Проверены радиусы вне модалки и в открытом шите, overrides типографики, pending-активация, RTL, контракты таблиц и меню, а также shared-input поиск.

Полный каталог: **32 теста прошли**, анализатор не нашел замечаний. Реестр проверяет уникальность идентификаторов, покрытие публичных виджетов, связанные страницы и поиск по API; проверена независимость состояния соседних примеров.

Независимый просмотр с выполнением smoke-проверок охватил все 21 канонические страницы компонентов: ширина 320, локальные проверки темного оформления, текста 2× и RTL, прокрутка содержимого. Переполнений и исключений не обнаружено. Замечания о взаимном влиянии соседних примеров и наследовании клиентского оформления устранены.

Release-сборка macOS прошла. Для команды использован установленный Xcode 27 через `DEVELOPER_DIR`; системный выбор Xcode не менялся. Перед сборкой обновлены генерируемые сведения о зависимостях, чтобы Swift Package Manager включал нативный plugin настроек. Веб-сборка также прошла.

Дополнительная независимая проверка поиска подтвердила замену внешних controller/FocusNode при открытом поле, переход к внутреннему focus node, отключение и удаление компонента без освобождения клиентских объектов.

## Упрощение навигации после проверки владельцем

Первый вариант с отдельными страницами категорий усложнил поиск компонентов.
Промежуточные страницы удалены: на главном экране видны названия всех семейств,
сгруппированные заголовками. Убрана вводная инструкция и длинные имена API из
списка; поиск по API сохранен. «Примеры» открывают готовый экран сразу, без
промежуточного списка связанных компонентов. Вкладка оформления названа
«Настройки», чтобы отличать ее от компонентов темы.

Все 21 переход проверены из главного списка. 32 теста каталога проходят,
анализатор без замечаний. Обновлены снимки светлой и темной темы; новая навигация
просмотрена на iPhone 17 Pro в симуляторе после hot restart.

вкладкам. Неподключённые `component_catalog.dart`, `catalog_workspace.dart`,
`component_registry.dart` и `catalog_settings.dart` удалены по решению владельца;
их последняя версия есть в коммите `f94c887`. Строки выше про реестр и его
проверки описывают состояние на 4 октября.

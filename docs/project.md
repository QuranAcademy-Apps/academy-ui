# Academy UI

Общая дизайн-система в отдельном репозитории `QuranAcademy-Apps/academy-ui`. UI вынесен в независимый пакет [academy_ui](../packages/academy_ui/README.md), который можно подключать из других Flutter-проектов, включая Zikro. Пакет не содержит функций Quran или Yalla, сетевых сервисов, авторизации и продуктовых данных.

Источники: дизайн-система Yalla и механизм модалок quran_flutter. Принятые правила: Cupertino, светлая/тёмная/системная темы, SF Symbols; Blur 20 только для навигационных элементов; непрозрачные таблицы, карточки и обычные поля. Раскрывающийся навигационный поиск использует выбранный эффект оформления (по уточнению пользователя). Модалки учитывают клавиатуру и сохраняют вложенную навигацию при повороте.

История решения и инвентаризация: [план](plans/design-system-migration.md). Текущие проверки: [task](tasks/2026-09-26-design-system-plan/task.md).

Самостоятельное приложение с полным каталогом: [Academy UI Catalog](../apps/academy_ui_catalog/README.md). Оно подключает библиотеку через относительный path и имеет отдельные оболочки macOS/iOS/Android/Web.

Библиотека разделена на `app`, `theme`, `foundation` и семейства `widgets`.
Добавлены формы, Select/MultiSelect, Autocomplete, календари, поля даты/времени,
picker, slider, popover и tooltip с оформлением Academy. Принципы композиции
сверены с Forui; сам пакет не подключён. Владение состоянием и совместимость
старых путей описаны в [архитектуре дизайн-системы](design-system-architecture.md).

Цвета библиотеки доступны через `AcademyColors` (аналог iOS `ThemeColors`). `AcademyPalette` задаёт стандартную палитру, `AcademyColorsData` позволяет полную или частичную замену. Клиент передаёт `AcademyApp.colorsBuilder`; яркость и акцент поступают в фабрику явно. Статусы, сегменты, тень сегмента, фон страницы, модальный барьер и цвета навигационных эффектов входят в контракт. Выбор и хранение палитры остаются ответственностью приложения.

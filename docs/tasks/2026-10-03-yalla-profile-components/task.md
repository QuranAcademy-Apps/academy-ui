## Goal

Добавить в `packages/academy_ui` небольшой набор общих компонентов, которых не хватает для экранов профиля, поездок и документов Yalla, и показать их в каталоге `apps/academy_ui_catalog`. Компоненты общие: без предметной логики Yalla (поездки, документы, паломники, телефон, карты).

## Out of scope

- Предметные виджеты Yalla: двуязычная карточка «Я потерялся», карточка поездки с маршрутом, блок отеля с картой и звонком, вход по номеру и код. Они остаются в приложении.
- Сетевые сервисы, авторизация, хранение данных.
- Подключение Academy UI к приложению Yalla (отдельное решение в `yalla-app`).
- Изменение существующих публичных API и внешнего вида имеющихся компонентов, кроме расширений ниже.
- Чужие незакоммиченные изменения в рабочем дереве (в основном каталог): сохранить, не откатывать, не смешивать с этой работой в одном коммите без явного указания владельца.

## Decisions and ownership

Принято владельцем (2026-10-03): добавить предложенные компоненты. Приоритет: 1–4 и 8, затем остальные. Все метрики брать из токенов темы (радиусы, `AcademyTokens`, `AcademyPaddings`), цвета — из палитры; тёмная и светлая темы, RTL, крупный шрифт, Reduce Motion, зона нажатия не меньше 44, один именованный semantics-узел на действие.

| # | Компонент | Требование |
| --- | --- | --- |
| 1 | `AcademyValueRow` | Строка таблицы «подпись слева, значение справа». Значение переносится при крупном шрифте с правым выравниванием. Режим `readOnly` с иконкой замка. Опциональные подзаголовок и `onPressed`. Строится на `AcademyRow`. |
| 2 | Деструктивный `AcademyRow` | Параметр тона (`AcademyTone.error`) у `AcademyRow`: красные подпись и плитка иконки по палитре, без ручной передачи цвета. |
| 3 | `AcademyActionButton` | Крупная кнопка высотой не меньше 64: круглая иконка слева, заголовок и подпись справа. Варианты primary и tinted. Состояния disabled и pending как у `AcademyButton`, тот же отклик нажатия. |
| 4 | `AcademyPillButton` | Малая таблетка-действие с иконкой и текстом, видимая высота 36, зона нажатия 44, tinted-заливка по палитре. Отдельно от `AcademyMenuButton` (тот открывает меню). |
| 5 | `AcademyTimeline` | Вертикальные этапы: заголовок, надпись-дата, подпись; состояния «пройден / текущий / впереди»; линия между точками. Семантика: порядковый номер и состояние. |
| 6 | `AcademyStatGroup` | 2–3 колонки «подпись + значение» с выравниванием слева/по центру/справа, перенос при крупном шрифте в вертикальный список. |
| 7 | `AcademyTableHeader.action` | Заголовок секции с текстовым действием справа («Изменить»), иконка опционально, зона нажатия 44, регистр заголовка задаётся параметром (в Yalla — обычный). |
| 8 | `AcademyRowIcons` | Именованные цвета плиток иконок строк: person, trip, document, alert, calendar, settings, info, hotel, passport. Значения из согласованного набора (см. макет), с адаптацией для тёмной темы. |
| 9 | `AcademyRow.action` | Строка-действие «текст слева, акцентное действие справа» (например «Данные не заполнены — Добавить»), вся строка нажимаемая. |

Ownership: компоненты не владеют данными и состоянием, принимают значения и callbacks. Анимации (если есть) освобождаются в `dispose`.

## Apple typography

По указанию владельца приоритет для типографики — [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/typography#Large-default), а не размеры HTML-макета. Используется шкала iOS при стандартном размере Dynamic Type:

| Элемент | Стиль Apple | Размер / высота строки |
| --- | --- | --- |
| Подпись и значение строки | Body Regular | 17 / 22 |
| Заголовок этапа, действие строки | Headline / emphasized Body | 17 / 22, Semibold |
| Заголовок большой кнопки | emphasized Callout | 16 / 21, Semibold |
| Малые кнопки и значения статистики | emphasized Subhead | 15 / 20, Semibold |
| Описание этапа | Subhead Regular | 15 / 20 |
| Даты и пояснения большой кнопки | Footnote Regular | 13 / 18 |
| Заголовок секции с действием, подпись статистики | Caption 1 Regular | 12 / 16 |

Распределение стилей по элементам — решение библиотеки; HIG определяет шкалу, но не предписывает каждому кастомному компоненту конкретный стиль. Сохранены системный шрифт, масштабирование текста, адаптивная композиция при 2×, RTL и зона нажатия минимум 44. Значения tracking для 11–19 pt уточнены по таблице SF Pro; API переопределений клиентской типографики сохранён.

- 2026-10-03: типографика профиля приведена к шкале iOS; Caption отделён от Footnote, Callout получил высоту строки 21. Capture на macOS использует локальный SF Pro вместо Inter. При крупном тексте AcademyRow.action переносит действие под подпись, сохраняя выравнивание у конца строки: подпись получает полную ширину и слова не разрываются из-за соседней кнопки.

Проверка Apple-правок: полный набор библиотеки — 200 тестов; после адаптации строки повторены 21 профильный тест и 2 проверки каталога/capture. Обе темы и 2× RTL просмотрены с локальным SF Pro. Анализ пакета и каталога и web-сборка прошли.

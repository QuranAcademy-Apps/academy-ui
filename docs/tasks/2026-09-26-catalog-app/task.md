# Самостоятельный Academy UI Catalog

Запрос: отдельное приложение со всей обсуждавшейся дизайн-системой.
Решение: перенести прежний package example в `apps/academy_ui_catalog`,
подключить `academy_ui` по относительному пути, добавить все группы каталога.
Самостоятельные оболочки macOS/iOS/Android/Web; release macOS — локальный артефакт.

Прочитаны `docs/project.md`, README библиотеки, существующий каталог и публичные
API компонентов. Используем ранее прочитанный flutter-scalable-app: значения
демонстраций принадлежат экрану, внешнее оформление — app controller/store.
Без изменений исходных Quran/Yalla и без копии библиотечного UI в приложение.

- [ ] Самостоятельный проект и нативные оболочки.
- [ ] Разделы со всеми обсуждавшимися компонентами и модалками.
- [ ] Интерактивные сценарии и сохранение оформления.
- [ ] Analyzer, каталог-тесты, web и macOS сборки.
- [ ] Документация запуска и локальный macOS артефакт.

Публикация в магазинах, сертификаты и продуктовый bundle ID Zikro не входят в задачу.

macOS: системный xcode-select указывает на CommandLineTools, поэтому первая
сборка не нашла xcodebuild. Найден `/Applications/Xcode 27.app`; для сборки
используем локальный DEVELOPER_DIR, системное значение не меняем.

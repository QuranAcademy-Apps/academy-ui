# Academy UI Catalog

Самостоятельное приложение со всей обсуждаемой дизайн-системой. Подключает
`packages/academy_ui` как зависимость; код компонентов в приложение не копируется.

Четыре вкладки:

- Каталог: кнопки, поля, выбор, таблицы/карточки, навигация/меню, состояния/тосты,
  прогресс/чек-листы, цвета/текст/иконки, анимации/подсказки.
- Quran: объединённые кнопки, раскрывающиеся списки, компактные сегменты и кнопки,
  меню с иконками/галочками, двойной шеврон, анимированное раскрытие поиска.
- Модалки: контент, форма и клавиатура, поиск, подтверждение, вложенные страницы,
  autoHeight, длинный список, полная высота, тост внутри модалки.
- Оформление: system/light/dark, все стили навигации, акценты; настройки сохраняются.

```sh
cd apps/academy_ui_catalog
flutter pub get
flutter run -d macos
# либо flutter run -d chrome, либо подключённое iOS/Android устройство
```

```sh
flutter analyze --no-pub
flutter test --no-pub
flutter build macos --release --no-pub
flutter build web --no-pub
```

macOS-приложение: `build/macos/Build/Products/Release/Academy UI Catalog.app`.
Нативный идентификатор отдельного каталога: `app.quranacademy.academyUiCatalog`.
Это не bundle ID будущего продуктового приложения Zikro. Мобильные проекты
созданы, сборки/подпись для публикации в App Store/Google Play не выполнялись.

iOS-проект использует Swift Package Manager. Он явно включён в `flutter.config`
каталога, чтобы глобальные настройки Flutter не отключали нативные плагины.
После изменения этой настройки выполните `flutter pub get` перед сборкой.

Blur 20 применяется к навигации и поиску; таблицы и обычные поля непрозрачные.
Тосты поддерживают top/bottom, leading/trailing icons, смахивание и удержание.
Для проверки клавиатуры на телефоне откройте форму, прокрутите к последней кнопке,
скройте клавиатуру; повторите в поиске и на вложенной странице, затем поверните экран.

[API библиотеки](../../packages/academy_ui/README.md).

Каталог использует стандартные скругления, отступы, типографику и цветовые роли
библиотеки. Редакторов этих значений нет; прежние сохранённые изменения не
применяются. В «Оформлении» доступны тема, акцент, стиль навигации, пропорции
таббара и пример палитры приложения.

В разделе «Поля и выбор» показаны поиск, обычное поле, поле с иконками с обеих
сторон и поле с заголовком «Имя». Все используют общую основу ввода и радиус 12.
Оба варианта сегментированного переключателя используют `AcademySegmentedControl`.

Новые разделы каталога:

- **Формы, поиск и выбор** — валидация и сброс формы, выбор языка и тем через меню,
  MultiSelect, недоступное поле, асинхронные подсказки и ошибка с повторной попыткой.
- **Календари и выбор значений** — поля даты/времени, календарь, период, лента дней,
  колёсный выбор и slider.
- **Фокус и всплывающие подсказки** — tooltip, popover и состояния взаимодействия.

Проверьте Enter/Space, Tab и Escape; подсказку можно вызвать наведением или удержанием.
[Архитектура и контракт компонентов](../../docs/design-system-architecture.md).

Стандартное оформление использует системные фоновые роли iOS и синий акцент.
Сохранённый прежний стандартный navy-акцент заменяется новым при чтении настроек;
остальные выбранные акценты сохраняются. Панель Select занимает полную ширину поля.
